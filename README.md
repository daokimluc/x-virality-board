# daokimluc X Virality Score

Personal daily X narrative dashboard for [@daokimluc](https://x.com/daokimluc).

**Live:** https://daokimluc.github.io/x-virality-board/

Built from the [x-virality-score](https://github.com/monkeyteamvip/x-virality-score) board starter. Not the demo kiosa-board.

## Local preview

```bash
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

## Data

- `index.html` — board UI
- `data.json` — daily digest payload (hits, drafts, patterns)
